Connect WooCommerce for order lookups.

Noctiv can answer "Where is my order?" from your live WooCommerce orders. It only reads. It never changes anything in your store.

Create a read-only key (phone is fine)

  1. In WordPress open WooCommerce, Settings, Advanced, REST API and tap Add key.
  2. Description: Noctiv. User: an administrator. Permissions: Read.
  3. Tap Generate API key. Copy the consumer key and the consumer secret. WooCommerce shows the secret only once.
  4. In Noctiv open Integrations, WooCommerce, paste the store address, key and secret and tap Connect.

Your store needs WooCommerce 3.5 or newer and permalinks other than "Plain" (Settings, Permalinks). If your host strips the Authorization header, the connection will say the store refused the key; ask your host to pass it on.

What Noctiv reads

Order number, date, status, shipment tracking and the names of the items. Never phone numbers, addresses or payment details. An order is used only when the sender's e-mail matches the billing e-mail on the order.

Tracking

WooCommerce itself has no tracking field, so Noctiv reads it from the common Shipment Tracking plugin, or from a customer note that says "Tracking number: ...". If a shipped order has no tracking, Noctiv does not guess: the e-mail comes to you.

When it hands over to you

Order not found, cancelled, refunded, on hold, shipped without tracking, shipped more than the number of days you set in Settings (default 14) ago, a refund, return or address change request, or an angry or chargeback e-mail.

Disconnect

In Integrations tap Disconnect and delete keys. We delete the saved key. Only you can revoke a key in WooCommerce, so also delete it under WooCommerce, Settings, Advanced, REST API.
